# Passage usage space

The reader may offer an optional “View usage in space” action. Load `js/usage-space.js` as a normal script after the reader markup, then call `window.MelosUsageSpace.open(query, author)` with the current search term and optional author filter. `window.MelosUsageSpace.close()` closes the view. The script creates and removes its modal itself and injects only `.mus-*` scoped styles.

The viewer requests `GET /api/usage-space?q=...&author=...&limit=80` and plots only finite `x`, `y`, `z` coordinates returned by the API. It centers the returned coordinates and scales all three dimensions by one common factor, so the display preserves relative 3D distances before perspective projection. Dragging or arrow keys rotates the view; scrolling, zoom buttons, or plus/minus keys zoom. Hovering previews a passage; clicking selects it. The detail shows the supplied text, citation, and `match_reason` when available, so a thematic candidate is identified as such even if it lacks the queried form. A selected passage also has a same-tab “Read in Melos” link to `/?id=...` using the opaque passage ID, and a separate safe HTTP(S) source link. “Nearest” means Euclidean distance among the supplied three coordinates. Authors have distinct colors within a result set.

The modal always includes a scrollable passage list usable without the plot. The close button, Escape key, and backdrop close it; focus returns to the invoking control. The server's `method` and `warnings` are displayed. Empty or failed requests receive explicit messages. No sample or invented points are substituted.

The axes are deliberately unnamed: position is a feature or embedding projection, not geography, time, literary influence, or an independently established interpretation. The plot draws no influence arrows. Numeric dates are displayed only when a point also carries `date_source`; an absent source leaves chronology unshown. Null, blank, and year-zero values are not displayed as dates. If the API exposes dates, it should pass through that source field as well as `date_start` and `date_end`.
