↺ Repair loop

Entered from stage 5–6 on any blocking fail.

  1. Deterministic fixes: dialectize (τηλόθεν → πήλοθεν), accent / psilosis, slot swap of right shape
  2. LLM repair with the failing linter records + slot suggestions → back to 4

Stop: no blocking fails · or 3 LLM rounds · or 90 s/line · or score flat for 2 rounds. Halted candidates still shown; overrides need a typed reason.

✎ Live editor (human in the loop)

The owner edits a word → lint stage 5 only, debounced 120 ms.

  • Scan + L1/L2/L7/L8/L9 ≤ 150 ms
  • Click a word: slot suggestions of the right metrical shape, same concept, attested in the author, ranked, each with its parallel missing
  • Click a form: other cases / dialect spellings that fit

edit → back to 5, never to the LLM unless asked

Latency budgets (p95)

  • keystroke lint ≤ 150 ms
  • slot suggestions ≤ 500 ms
  • full lint ≤ 1.5 s
  • retrieval ≤ 4 s / line
  • LLM proposal ≤ 20 s
  • repair ≤ 90 s / line
