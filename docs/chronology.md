# Author chronology metadata

`data/metadata/chronology.json` is generated by `python scripts/collect_chronology.py`
from a saved Wikidata API response. Reparse without downloading with
`python scripts/collect_chronology.py --cached`.

Each author retains every downloaded birth, death, floruit, and work-period
statement, including conflicting and deprecated claims, qualifiers, reference
fields, and Wikidata time precision. `biographical_claim_envelope` is the broad
min/max envelope across non-deprecated claims; it is for conflict inspection,
not display as a person's lifespan.

`author_chronology` selects one referenced, non-deprecated birth claim, or a
floruit claim when no usable birth claim exists. It prioritizes explicit
earliest/latest qualifiers, then Wikidata preferred rank, narrower interval,
reference count, and stable statement ID. `sort_start`, `sort_end`, and
`sort_year` describe that selected claim only. `sort_year` is the interval
midpoint used for a coarse timeline order, not an established event date.
The full selected claim, including source statement ID and reference fields,
is available under `selected_claim`. Display should say “author date claim”
and identify `claim_kind` (birth/floruit); it must not call the selected range
a lifespan or a poem composition date. No passage receives `date_start` or
`date_end` from author metadata.

`reference_types` are mechanical labels from Wikidata reference properties:

| Label | Wikidata property seen | Interpretation |
| --- | --- | --- |
| `stated_in_item` | P248 | A Wikidata “stated in” item; its authority has not been independently assessed. |
| `reference_url` | P854 | A reference URL; its evidence has not been independently assessed. |
| `imported_project_only` | P143 | The claim cites a Wikimedia project import only. |
| `authority_identifier` | P268 | The claim cites an authority identifier, possibly with retrieval time. |
| `other_reference` | Other fields | The source type has not been classified. |

These labels describe the reference mechanism, not historical confidence.
In the current source snapshot, Stesichorus and Bacchylides selected claims
have `imported_project_only` references, and Ibycus has an
`authority_identifier` reference. The `uncertainty` and `reference_notes`
fields expose those limitations for the interface.
