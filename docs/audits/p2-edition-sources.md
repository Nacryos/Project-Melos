# Second-pass edition and scan source audit

Audited 2026-09-30. This is a source-discovery and rights gate under `docs/corpus-contract.md` and `docs/augmentation-contract.md`, not an acceptance of extracted passages. `PASS` permits the stated, bounded staging route; `WARN` permits links, metadata, or clearly restricted local reference use; `FAIL` rejects the proposed full-text route. Each textual output still needs raw bytes, exact URL, SHA-256, edition, page/fragment locator, parsing and visual checks, and the independent text audit. Historic public-domain assessments below concern U.S. use in 2026; they are not worldwide licenses or a claim that modern editions are free.

## Operational boundary

For selected historical pages, save IIIF image bytes (or PDF), exact URL, and hash before OCR; retain the page/scan-leaf correspondence from the saved IIIF manifest and `scandata`. The existing Lyra/Bergk DjVu XMLs are Latin-language OCR **of Greek-containing scans**, not Greek transcripts. Machine Greek OCR can be indexed as a reference candidate, but source-text quality requires human image comparison. Keep an edition's Greek, translation, apparatus, commentary, and modern scholarly inference in distinct records. Title-page and rights evidence must attach to the exact edition used; a freely readable webpage alone is not a bulk-reuse grant.
