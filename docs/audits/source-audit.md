# Source discovery audit — lyric corpus

Audited 2026-09-29 against `docs/corpus-contract.md` and the data-extraction skill. This is a source-level gate, not acceptance of extracted passages. A collector must still retain exact download URLs, raw bytes and hashes, edition and citation evidence, row-specific rights, and extraction logs. `PASS` permits staged ingestion for further audit; `WARN` permits only appropriately labeled staging or a narrower subset; `FAIL` rejects the stated source URL or claim.

## Open source checks

- Lexica and other commentary sources: awaiting exact source URLs, terms, and file/page examples. A generic home page, search result, or an inaccessible endpoint is not a source-discovery pass.
- Archive.org scans: inspect printed title pages and copyright pages for all chosen items. OCR text is evidence of a scan, not proof that a line is Greek lyric or correctly attributed.

## Downstream audit gate

For every collector output, sample records must trace `processed JSONL record → raw_path + raw_sha256 → exact source_url → source text span`. Verify that raw bytes were actually downloaded and saved, labels/edition/chronology came from source metadata or cited mappings, and no Greek, translations, or bibliography were authored from memory. A source PASS above does not lift this requirement.
