# Lexicon, Concepts and Headword search — frontend for release O (2026-10-09)

Release O added a corpus headword index and lemma endpoints with no user interface. This release adds the
interface. Bar: Logeion (dictionaries side by side, frequency, examples), TLG (lemmatised and proximity search)
and Perseus/Protagoras (forms of a headword). Only `js/`, `css/`, `*.html` and `tests/` were edited, plus the
page list in `scripts/build_frontend.mjs` (the build has a fixed list of shipped pages; the two new pages had to
be added to the reader-only release). `backend/` was not touched.

## What readers can now do

- **Lexicon page** `lemma.html?lemma=σελήνη` (or `?q=σελάννα`, `?q=moon`): the dictionaries side by side (tabs on
  phones), with every sense and the full entry; frequency (occurrences, rate per 10,000 words, rank) with bar
  charts by author, genre and period, small periods flagged "few texts, rate unreliable" and undated authors drawn
  apart and labelled; a keyword-in-context concordance (20 lines a page, by author date or author name, author
  filter by choosing a bar, each line opens the passage in the reader, other editions of the same line folded
  under it); collocations with "together" counts, "times more often than chance", the log-likelihood score and a
  plain explanation; every inflected form found, each a search link. A query that is a form or an English
  meaning says how it was read ("ἀσυννέτημμι was found as a form of ἀσυνετέω") and offers the other readings.
- **Concepts page** `concept.html?q=moon`: the headwords for the meaning with where each comes from (dictionary
  meaning or meaning index); a timeline of rate per 10,000 words by period (plain SVG, one colour per headword,
  tick to show or hide, hover or tap for counts, table view), undated authors in a separate dashed column marked
  with open circles; small-sample periods faded and flagged; companions per period for a chosen headword; an
  example passage per period (from the author who uses it most), each opening the reader. The wording "Dates are
  author lifetimes, not composition dates" appears in the header, the chart note and the footer.
- **Home search**: a "Headword" mode. One word lists every occurrence of any form, with the headword, gloss,
  counts and forms found at the top and a link to the lexicon page; two to six words find the headwords side by
  side in any forms; "Near" allows up to 20 other words between them in any order. URLs keep the mode
  (`?q=…&mode=lemma&near=1&window=5`).
- **Other editions**: search results now show "N other editions of this passage" (from the API's `editions`)
  with a link to each; headword-search lines fold copies of the same line from another collection the same way
  (a formula repeated within one text, e.g. ῥοδοδάκτυλος Ἠώς, stays separate).
- **Word panel**: the headword is a link to its lexicon page, with "All forms, frequency and passages in the
  lexicon →" under it.
- **Site menu**: Lexicon and Concepts in the reader's header (kept visible on phones), and on both new pages.
- Plain names: the passage title and result cards use `display_author` / `display_work` (Homer · Iliad, not
  homerus-epic · ilias); the hybrid match reason names the new headword signal "Same headword".

## Click-to-headword timings

Method: `measure.py` (session scratchpad), Python Playwright, poems Sappho 1, 31, Alcaeus 326, Anacreon 358, ten
words; desktop 1440×900; mobile 390×844 touch, 4× CPU throttle, Fast 3G (562 ms latency, 1.44 Mbit/s). "Cold" =
tap as soon as the words are clickable; "hover" = hover (desktop, 500 ms) or touchstart (mobile, 150 ms) first.
Before = live site before this release; after = this frontend against the live API through a local gzip proxy.

| | headword before | headword after | first dictionary before | first dictionary after |
|---|---|---|---|---|
| Desktop, cold | 501 ms (p90 985) | **18 ms** (p90 186) | 501 ms (p90 1,182) | **250 ms** (p90 983) |
| Desktop, hover | 13 ms | 16 ms | 116 ms (p90 521) | **18 ms** (p90 369) |
| Mobile, cold | 1,226 ms (p90 2,621) | **67 ms** (p90 80) | 1,248 ms (p90 2,715) | **732 ms** (p90 904) |
| Mobile, hover | 951 ms (p90 2,404) | **63 ms** (p90 76) | 951 ms (p90 2,495) | **437 ms** (p90 905) |

Why: the batch headwords request (`POST /api/words/headlines`) now starts together with the passage request
instead of in idle time after it, and a click that arrives before it takes its headword when it lands; the
headword's dictionary-only lookup (`/api/word?form=L&lemma=L`, a few ms on the server) runs beside the full
form analysis instead of after it, and hover prefetches it. On Fast 3G every request costs at least one 562 ms
round trip, so a first dictionary under 500 ms after a cold tap is not reachable without the dictionary text
being in the batch payload (backend gap 1).

## Backend gaps (written down, not changed)

1. **No dictionary text before a click.** `/api/words/headlines` carries the gloss but not the dictionary senses;
   a cold tap on 3G waits one round trip for the dictionaries. Optional `senses` per token, or a compact
   `GET /api/lemma/entries?lemma=` (the `lemma=` fast path returns every top-level `/api/word` field, 7–45 KB
   gzipped for common words: φαίνω 45 KB, ἀνήρ 19 KB).
2. **`/api/lemma/search` has no text.** Results carry citations but no excerpt or match offsets, so headword
   search uses `/api/lemma/concordance` for its lines and `/api/lemma/search` only for the forms facet.
3. **Concordance and proximity do not fold editions.** Sappho 34 and Alcaeus 326 appear once per collection;
   the frontend folds same-author, same-text lines from different collections, but the service should return
   `editions` as `/api/search` does.
4. **No period filter on the concordance.** Concept examples per period use the author with most occurrences in
   that period (`author=`); `period=` (and `undated=true`) on `/api/lemma/concordance` would allow several
   authors per period.
5. **Diachrony collocates skip undated authors**, and there are no example passages per period in
   `/api/concept/diachrony`.
6. **Small periods.** Late antique has 4,714 words and Roman imperial 30,389 in scope, so one poem swings the rate
   (θάλασσα family spikes to ~30 per 10,000 in Roman imperial). The frontend flags periods under 50,000 words;
   the API could return a sample-size flag or an interval.
7. **Gloss-mapping noise in concepts.** "moon" brings Ἰώ (Io) and Οὐρανία (Urania); "love" brings φίλος first;
   "sea" brings ναύτης "a mate or companion". `matched_terms` are stems ("lov"); the frontend shows the typed word.
8. **Weak collocate glosses**: πότνα has none; ὁδός "a threshold", ὅθεν "from whom", κύκλος "a ring". Theocritus
   2's refrain inflates σελήνη's Hellenistic collocates (πότνα, ὅθεν, ἔρως, ἱκνέομαι 24× each); counting
   distinct passages or poems would help (the page says so in words).
9. **ἔρος and ἔρως are separate headwords**, so Sappho's ἔρος is not counted under ἔρως and the ἔρως page never
   mentions it; a "variant of" link between headwords would let the lexicon page combine or cross-reference them.
10. **Chronological concordance order**: Homer's Epigrams sort before the Iliad (same author date); a work order
    within an author would read better.
11. **`/lexicon` 404 on production**: `vercel.json` rewrites `/lexicon` to `lexicon.html`, which the reader-only
    build does not ship (the older discovery page). The new page is `lemma.html`; a rewrite `/lexicon` →
    `/lemma.html` (outside this release's edit scope) would make the short URL work.

## Checks

- `npm run test:frontend`: 492 tests pass (new `tests/lemma-pages.test.mjs`, 7 tests; build-profile, word-panel
  and title tests updated for the new pages, the parallel dictionary lookup and display names).
- Human-style checks with Python Playwright (`ui_check.py` in the session scratchpad), headless, 1440×900 and
  390×844 touch, real clicks, taps and hovers: Headword search (σελήνη, load more, open a line), phrase
  (ῥοδοδάκτυλος ἠώς: 60 passages) and Near (σελήνη ἀστήρ: 8), editions expander (σελάννα) and opening an
  edition, word panel link (σελάνναν in Sappho 34 → σελήνη), lexicon pages for θάλασσα, ἔρως, the Aeolic
  ἀσυννέτημμι (→ ἀσυνετέω, Alcaeus, 2 occurrences) and "moon", author filter, sort and paging, frequency tabs,
  dictionary tabs on phones, concept pages for moon, love and θάλασσα, chart tooltip by hover and tap, headword
  picker, series toggle. Every clickable element shows the pointer cursor; no console errors; no sideways scroll
  at 390 px.
