# Local semantic retrieval

As of September 2026 the deployed encoder is [BAAI/bge-m3](https://huggingface.co/BAAI/bge-m3), a 1024-dimensional multilingual dense retrieval model, pinned to revision `5617a9f61b028005a4858fdac845db406aefb181`. Its authors document support for more than 100 languages and up to 8192 tokens. This installation uses only dense vectors and limits each model input to 512 tokens for predictable RTX 3070 laptop memory and indexing time. Every passage is tokenized into consecutive windows within that limit; each window is embedded, then the window vectors are averaged with token-count weights and normalized into one passage vector. The original complete text remains in SQLite. This pooling covers late text, though a single average can dilute a short theme within a long passage. The 512-token window is an engineering choice, not a model constraint. CUDA runs at half precision with batch size 32; a bounded 128-passage benchmark on this machine measured about 124 passages/s against 33 passages/s for float32 batch 8 before full-window pooling. The exact speed varies with passage length and number of windows. CPU falls back to float32.

The initial build uses `py -3.13 scripts/build_embeddings.py`. It indexes at most 20,000 eligible passages, prioritizing lyric authors and the lyric collector, then English translations, and records both `count` and `eligible_count` in `data/embeddings/manifest.json`. Run with `--max-passages 0` to finish all eligible material. The manifest also records the number of encoded windows, and each row has its own window count. Completed batches are stored in `data/embeddings/checkpoint.sqlite`, so an interrupted build resumes and unchanged passages are not re-encoded. Greek/English `text`, `translation`, and `commentary` records of acceptable source quality are eligible; OCR, mixed-content, review-needed, apparatus, and reference records are excluded from this index. The reader's lexical search still covers the source database according to its own rules.

English queries can match indexed English translations or commentary directly. A translation hit carries its `parent_id` when the source provides one. Each result reports the language and kind that produced its vector. Direct Greek hits are also available, but there is no validated Ancient Greek benchmark for this particular model and corpus. A modern multilingual benchmark cannot establish Ancient Greek retrieval quality. [Krahn et al.](https://aclanthology.org/2023.alp-1.2/) evaluate Ancient Greek sentence retrieval and translation bias specifically, illustrating why this is a separate evaluation problem. The cosine score ranks passages within this index and is not a probability of historical or interpretive correctness.

Other current options considered: [Qwen3-Embedding-0.6B](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B) is an attractive local 0.6B encoder with a 100+ language claim and instruction-aware retrieval, but its published multilingual benchmark does not resolve Ancient Greek performance; BGE-M3 offers a simpler, established sentence-transformers path for this bounded build. [EmbeddingGemma](https://deepmind.google/models/gemma/embeddinggemma/) targets efficient local multilingual embeddings, though its 100+ language description similarly does not validate Ancient Greek. [DiffusionGemma](https://deepmind.google/models/gemma/diffusiongemma/) is an experimental text-generation model, not the EmbeddingGemma encoder. [Jev's publisher](https://www.jevtypesafeai.com/jev/architecture) describes a hosted typed decision API without published local model internals; it is not a drop-in local passage encoder and would require an external service. No corpus text is uploaded to an embedding API.

Before claiming reliable cross-language Greek search, assemble a held-out set of sourced Greek passages, English queries and relevant passage judgments, then measure Recall@k and compare direct Greek results against English translation bridges. The current interface presents the method and caveat rather than implying that validation has happened.
